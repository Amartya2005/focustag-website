# FocusTag

Marketing site for FocusTag — physical NFC checkpoints with mobile focus enforcement.

## Live locally

```bash
npx serve .
```

Open `http://localhost:3000`.

## Stack

- Single `index.html` (responsive desktop / tablet / mobile)
- Three.js product model (WebGL; photo fallback if unavailable)
- Product photography in `assets/`

## GitHub Pages

Repo Settings → Pages → Deploy from branch `main` → `/` (root).

After Pages is on: https://amartya2005.github.io/focustag-website/
